1️⃣ UI / Branding
| Property                 | Purpose       | Example / Use                                       |
| ------------------------ | ------------- | --------------------------------------------------- |
| `glide.ui.logo`          | Company logo  | Swap out default logo for portal branding           |
| `glide.ui.color.primary` | Primary color | Changes headers/buttons in Service Portal           |
| `glide.ui.color.accent`  | Accent color  | Highlights, hover effects, important buttons        |
| `glide.ui.font`          | Default font  | Ensures portal typography matches branding          |
| `glide.ui.header.title`  | Header text   | Customize portal header name without changing pages |


2️⃣ Form & List Behavior
| Property                       | Purpose               | Example / Use                                 |
| ------------------------------ | --------------------- | --------------------------------------------- |
| `glide.ui.list.editable`       | Enable inline editing | Can turn on/off quick editing for lists       |
| `glide.ui.show_empty_fields`   | Hide empty fields     | Cleaner forms for end-users                   |
| `glide.ui.session_timeout`     | Session duration      | Adjust UX to reduce frustration from timeouts |
| `glide.ui.mandatory_indicator` | Required field marker | Change style or text of “mandatory” asterisks |





3️⃣ Notifications & Messaging

| Property                                  | Purpose                        | Example / Use                                   |
| ----------------------------------------- | ------------------------------ | ----------------------------------------------- |
| `glide.email.from`                        | Default email sender           | Branding email notifications from company       |
| `glide.email.signature`                   | Default email signature        | Standardize email footers for notifications     |
| `glide.notification.show_activity_stream` | Show activity in notifications | Customize what gets seen in notification emails |




4️⃣ Feature & Workflow Toggles
| Property                  | Purpose                  | Example / Use                                       |
| ------------------------- | ------------------------ | --------------------------------------------------- |
| `glide.ui.portal.enabled` | Enable/disable portal    | Switch between Classic UI and Service Portal easily |
| `glide.workflow.debug`    | Debug workflow behavior  | Temporarily enable for testing automations          |
| `glide.ui.autocomplete`   | Enable field suggestions | Improves UX for reference fields                    |
