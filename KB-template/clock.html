Add an Additional Clock to the Windows Taskbar

Purpose: This article explains how to add an additional clock to the Windows taskbar without requiring an IT support ticket or administrative privileges.

(Optional) Additional clocks are useful when working with teams, vendors, or facilities located in different time zones, or when traveling between locations.


Process:

Configure an Additional Time Zone Clock

  1. Select the Search icon from the Windows taskbar.

    [Insert Screenshot – Windows Search Icon]
  2. Type Settings into the search box and select the Settings application from the results.

    [Insert Screenshot – Settings Search Result]
  3. Navigate to the Date & Time settings page and select Additional Clocks or Change under Additional Clocks.

    [Insert Screenshot – Additional Clocks Option]
  4. Check the box labeled Show this clock.
    1. Select the desired time zone.
    2. Enter a display name if desired.
    3. Select Apply and then OK.

    Example: Alaska Time Zone


    [Insert Screenshot – Time Zone Selection]
  5. Hover your mouse over the date and time displayed in the taskbar.
    The newly configured clock will appear alongside your local time zone.

    [Insert Screenshot – Multiple Clocks Display]

Note: Windows supports multiple taskbar clocks, allowing users to quickly reference time zones without opening additional applications.

Note: Adding or modifying additional clocks does not change the computer's primary time zone.


Warning: Ensure the correct time zone is selected before saving changes. Choosing the wrong time zone may result in scheduling errors when coordinating meetings or support activities.


Benefits:

  • Track time in multiple regions simultaneously.
  • Coordinate with remote offices and vendors more efficiently.
  • Reduce scheduling mistakes when working across time zones.
  • No administrative rights are required.

Summary:

Users can add one or more additional clocks directly through Windows Date & Time settings. This provides quick visibility into other time zones from the taskbar and is especially useful for travel, remote collaboration, and cross-regional support activities.
