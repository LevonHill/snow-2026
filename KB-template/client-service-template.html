Microsoft Edge URL Blocklist Configuration

Purpose: This article explains how to configure website blocking and allowlisting in Microsoft Edge using Windows Registry settings. This configuration is intended for non-domain joined devices, such as training computers, where centralized management tools are not available.

(Optional) Administrators can use this method to restrict access to approved websites without installing additional software or content filtering tools.


Process:

Configure Edge URL Blocklist and Allowlist

  1. Open Registry Editor (regedit.exe).
  2. Navigate to:
    • HKLM\Software\Policies\Microsoft
  3. Create a registry key named Edge.
  4. Under the Edge key, create the following subkeys:
    1. URLBlocklist
    2. URLAllowlist
  5. To create a blocklist:
    1. Open the URLBlocklist key.
    2. Create String Values named in numerical order (1, 2, 3, etc.).
    3. Set each Value Data field to the website you want to block.
  6. To create an allowlist:
    1. Open the URLAllowlist key.
    2. Create String Values named in numerical order (1, 2, 3, etc.).
    3. Set each Value Data field to an approved website.
  7. Restart the computer after making registry changes.

Note: The URLBlocklist key prevents access to specified websites, while the URLAllowlist key permits access to approved websites.

Note: Registry String Values should be numbered sequentially beginning with 1.


Warning: To block all websites except those explicitly approved, create a String Value named 1 in the URLBlocklist key and set the Value Data to *.

Warning: If all websites are blocked using the wildcard (*), be sure to allow edge://* so users can access Edge settings and internal browser pages.

Warning: Adding *. before a domain may limit access to only specific URLs and could prevent access to required subdomains.

Summary:

Microsoft Edge supports local website filtering through registry-based URLBlocklist and URLAllowlist policies. This configuration provides a simple method for limiting web access on standalone or training computers without requiring domain management or third-party software.
