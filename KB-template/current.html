Cisco Secure Client VPN

Fix: Start Menu Shortcut Broken

Issue

Cisco Secure Client VPN will not launch from the Start Menu. Clicking the shortcut does nothing or results in an error.

Cause

The Start Menu shortcut is no longer linked to the correct Cisco Secure Client executable. This commonly occurs after updates, partial installs, or profile migrations.

Resolution

  1. Open File Explorer
  2. Navigate to:

    C:\Program Files (x86)\Cisco\Cisco Secure Client\UI\Setup

  3. Locate csc_ui.exe
  4. Double-click the file to launch Cisco Secure Client
  5. Optional: Right-click csc_ui.exe and select Create shortcut to restore Start Menu access

Notes

  • Do not use vpnui.exe if it is missing or outdated
  • If csc_ui.exe is missing, reinstall Cisco Secure Client
  • Administrative rights are not required to launch the executable
