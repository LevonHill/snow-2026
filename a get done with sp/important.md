⭐ Popular Requests

Not a parent category, but a featured section on the homepage.

If you analyze six months of incident data, you'll likely find that 60–70% of requests come from a relatively small set of services. Feature those first:




If your objective is 50% ticket deflection, the catalog is only half the solution. The other half is automation. Each catalog item should:

Ask all required questions up front.
Route automatically to the correct assignment group.
Trigger approvals only when necessary.
Create fulfillment tasks without manual triage.
Present a relevant knowledge article before the user submits the request ("Did this solve your issue?").

That combination reduces not only phone calls but also the amount of manual work Tier 1 performs after a request is submitted.

From what you've shown, you're already thinking like someone designing a service, not just building forms. That's the mindset that turns a ServiceNow portal into a genuine self-service platform.

One thing most companies miss

The catalog isn't what creates deflection.

Confidence does.

If users trust that:

the portal is easy,
their request reaches the right team,
they get updates automatically,
and it gets resolved quickly,

they'll stop emailing the help desk because the portal becomes the faster, more reliable option.
